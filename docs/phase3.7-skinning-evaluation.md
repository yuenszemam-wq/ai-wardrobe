# Phase 3.7｜角色動畫及蒙皮進階：評估報告（2026-11-15）

## 結論

- **本輪沒有改變角色換裝的畫面。** 實作了雙四元數蒙皮（Dual Quaternion Skinning，2D 版本），但兩件測試外套的實測結果不一致：
  一件在大部分姿勢減少關節內側收縮，另一件在「一手叉腰」的手肘反而更差。為免在 iPhone 上令已校正的衣物變樣，預設仍是原本的線性蒙皮，
  雙四元數只作實驗選項（`setSkinBlend("dq")`），並以 `test/phase37.mjs` 持續量度。
- **暫不建議改用 Live2D。** 理由見下文；建議繼續改善現有網格（權重及關節修正），而不是換引擎。

## 實測數據（test/phase37.mjs，Avatar V2，12 個姿勢預設）

收縮＝相鄰頂點距離最多縮短幾倍（愈接近 1 愈好）；拉長＝最多拉長幾倍。

| 姿勢 | 收縮 LBS → DQ | 拉長 LBS → DQ |
|---|---|---|
| 一手叉腰 | 2.53 → 3.05（較差） | 1.76 → 2.11 |
| 一手伸展 | 2.24 → 1.95（改善） | 1.86 → 1.89 |
| 提起裙擺 | 1.35 → 1.31 | 1.38 → 1.44 |
| 雙手提裙 | 1.30 → 1.28 | 1.34 → 1.38 |
| Lolita | 1.39 → 1.36 | 1.40 → 1.40 |
| 其他 7 個 | 相同或改善 ≤ 0.03 | 相同或增加 ≤ 0.04 |

面積偏差總和：LBS 103.9、DQ 107.4。另一件外套（test/doll-logic.mjs 的網格）在「一手叉腰」收縮由 8.45 減至 7.65，
但純雙四元數會令手肘外側拉長至 2.15 倍（超過現有 2 倍的安全線），所以加入了按彎曲角度與線性混合的處理。

## 下一步建議（按效果／風險排序）

1. **關節修正權重**：手肘彎曲範圍（目前 36＋0.7×袖闊）按彎曲角度動態加闊；肩膊過渡（目前距肩關節 30–115px）改為按袖窿形狀計算，
   先以實機截圖比較，再決定是否套用到所有衣物。
2. **每個姿勢的修正網格**（現有「每個姿勢的衣物修正」延伸到關節位置）：只在使用者選擇時套用，不影響已保存造型。
3. **接縫檢查工具**：在衣服設定顯示衣身與袖子重疊範圍，讓使用者看到哪裏會露出空隙。

## Live2D 評估

- 授權：根據 Live2D 官方說明，年銷售少於 1,000 萬日圓的個人及小規模企業發佈 Cubism SDK 內容可免簽發佈授權及費用（「Expandable Application」除外）；
  超過門檻需要簽約及按平台付費。若日後把 App 商品化，需要重新評估。
- 技術限制：Live2D 模型需要在 Cubism Editor 預先切件及綁定（每件衣服都要人手製作變形器及參數），
  與本 App「上傳任何衣物相片、自由疊穿、去背後即時穿上」的流程不相容；亦需要額外的 SDK 及 WebGL 執行環境，增加 iPhone 記憶體及載入時間。
- 建議：保留現有自家網格；如日後只需要角色本身（頭髮、表情、呼吸）的動畫，可以考慮只把頭部做成 Live2D，衣物仍用現有系統。
