# Avatar V2：由完整人物圖拆出的可動 2D 角色

狀態：**獨立測試頁階段**（`/dressing/avatar-lab`）。未接入正式換裝頁，未修改 D1／R2。

## 素材來源

| 檔案 | 用途 |
| --- | --- |
| `scripts/doll-src/avatar_v2/source_full.png` | 使用者提供的完整二次元人物圖（1024×1536），**唯一美術基準** |
| `scripts/doll-src/avatar_v2/reference_bald.png` | 使用者提供的無髮參考圖，只用來補回被頭髮遮住的頭皮、額頭、眉、耳及外眼角 |

沒有使用任何 AI 重新生成圖片；全部像素直接取自以上兩張圖，或由鄰近像素延伸（見「補色範圍」）。

## 重新產生

```
python3 scripts/build-avatar-v2.py      # 需要 Pillow、numpy、opencv；約 45 秒；結果固定
```

輸出到 `public/doll/avatar_v2/`（會部署）及 `docs/avatar_v2/`（預覽，不部署）。
關節、切線等人工量度的座標全部在腳本開頭的常數內，改數值後重跑即可。

## 拆件方法

1. **基準圖**：原圖的身體 alpha 只有 253、背景有大量 alpha 1–20 的霧化雜點。先把 alpha 重新映射（≤24→0、≥248→255）、清除零碎色塊，再等比例 ×1.171875 放大到 1200×1800（兩者皆 2:3，沒有拉伸）→ `avatar_base_v2.png`。
2. **分開頭髮與身體**：以顏色（深啡／粉紅）找頭髮候選，再以「由軀幹出發的淺色連通區」定出身體；眼睛、瀏海縫隙、耳朵用人工指定範圍處理。
3. **身體底圖**：可見的身體用完整圖；頭髮遮住的頭部用無髮圖（先按臉頰／頸的膚色比例校正）。無髮圖的眼睛位置略有不同，所以先抹成膚色，眼睛一律用完整圖的。
4. **切件**：四肢沿骨骼方向切開，每個關節兩邊的部件都包含一個以關節為圓心的重疊圓（肩 38、肘 35、腕 24、髖 78、膝 46、踝 31 px）。部件遮罩先外擴 3px 再羽化，所以靜止時分界處兩邊都是完整不透明，不會出現半透明接縫。
5. **瀏海陰影**：瀏海投在額頭上的陰影及淺色髮尾跟隨頭髮層（換髮型時不會留在臉上）；遮罩 G 通道標明它們不是頭髮，換髮色時不會被染色。
6. 部件為緊密裁切的 PNG，位置（x、y、w、h）記錄在 `rig.json`，可還原到畫布原位。

## 圖層次序（由底到面）

後髮（左右馬尾、後髮）→ 褲下襯層 → 腳 → 小腿 → 大腿 → 骨盆 → 軀幹 → 手 → 前臂 → 上臂 → 頸 → 頭 → 側髮 → 瀏海

`pelvis_under` 是規格以外多出的一件：大腿轉動時，褲腳外側露出的位置由它補上原本的皮膚。

## 骨架

`rig.json` 的 `bones`：id、parent、rest_position、rest_angle、pivot、min_angle、max_angle、attached_assets。
引擎在 `shared/avatarRig.ts`（純 TypeScript，Forward Kinematics；另有拖動手腳用的兩節 IK）。
角度以度為單位，正數在畫面上是順時針；`_r`／`_l` 為角色本人的右／左（`_r` 在畫面左邊）。

## 使用方法

```tsx
<AvatarRigRenderer rig={RIG_V2} pose={pose} scale={k} hairStyle="twin_tails_long" hairColor="purple" accentColor={null} />
```

- 新增髮型：把六個部件（可少於六個）放到 `public/doll/avatar_v2/hair/<id>/`，在 `shared/avatarV2.ts` 的 `HAIR_STYLES` 登記位置，不用改渲染器。
- 髮色：`recolorHair` 按原本亮度重新著色（暗部按比例、高光向白色過渡），只改 RGB，不改 alpha。`*_accent.png` 的 R 通道＝挑染比重，主髮色及挑染色可分開設定。
- 衣物：`posedAnchors(rig, pose)` 取得目前姿勢下的錨點；`ATTACH_BONE` 列出各衣物部件應跟隨的骨骼；`singleImagePoseIssues` 判斷單張 PNG 的衣物在目前姿勢下是否可靠（不會假裝整張衣服會彎曲）。

## 還原度

`assembly_report.json`（腳本內）及 `test/avatar-logic.mjs`（由輸出檔案獨立重組）：
全部部件疊加後與基準圖的平均差約 0.14／255；差異大於 16 的像素佔人物約 0.8%，集中在頭髮與臉、身體的交界邊緣。
`assembly_compare.png` 以紅色標出這些像素。

## 補色範圍（不是原圖內容）

| 位置 | 做法 |
| --- | --- |
| 額頭、頭皮、眉、耳、外眼角 | 取自無髮參考圖，並非完整圖的像素 |
| 馬尾被肩膊及手臂遮住的部分（向內約 26px） | 由鄰近髮色延伸，較模糊 |
| 大腿在褲腳線以上、藏在內褲下的部分 | 由大腿膚色向上延伸 |
| 頸在下巴後面的部分 | 由可見頸部向上延伸 |
| 後髮在頭後面的部分 | 只有頭頂外圍向內約 18px，頭後面大部分是空的 |

## 已知限制／需要美術修整

1. **無髮時的眼睛上緣**：上睫毛原本被瀏海蓋住一部分，除下頭髮後上睫毛邊緣不整齊，兩眼之間有一條淡線。有瀏海的髮型看不到；沒有瀏海的髮型需要人手修整頭部圖。
2. **手臂向內收時**：手臂原本位置後面的馬尾是延伸補色，近看會模糊。要好看需要補畫完整的馬尾。
3. **後髮不完整**：這個髮型的後髮只有頭頂外圍一圈。頭部轉動幅度已限制在 ±10°。
4. 身體邊緣有少量殘留的髮色像素（手臂外側貼著馬尾的位置）。
5. 內衣是畫在身體上的；衣物穿在其上。
6. 關節只做小幅度調整（範圍見 `rig.json`），大幅度動作會露出切邊。
7. 單張 PNG 的衣服不會跟隨姿勢變形；要跟隨四肢需要 Phase 3 的衣物部件。
